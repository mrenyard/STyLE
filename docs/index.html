#

Working with STyLE the Semantically Templated and Layered Elements based CSS Framework

STyLE enforces the premise that semantic web documents and applications have all the necessary elements (hooks) for a fully fledged CSS framework. Through its layered approach of mangaging & ordering StyleSheets (& CSS rules), STyLE provides a variety of visually pleasing, user friendly and user centric UX components, layouts, patterns and web features.
